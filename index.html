周弈志 / Yizhi Zhou

04 / TEACHING

让知识，
成为探索的起点。

Web 开发与多媒体技术
本科课程教学

教授课程

Web程序设计（本科）
本课程介绍 Web 应用的基本原理与前后端开发方法，涵盖 HTML、CSS、JavaScript 等前端基础，以及基于 Spring Boot 的后端开发、HTTP 请求处理、接口设计、数据库访问和前后端数据交互。通过完整 Web 应用的开发实践，培养学生理解前后端协作机制、实现业务功能与调试程序的能力。
Web框架系统开发（本科）
本课程在 Web 程序设计基础上，介绍基于 Vue 等框架的 Web 系统开发方法，涵盖组件化开发、响应式数据绑定、前端路由、状态管理，以及与 Spring Boot 后端的接口对接和前后端分离开发。通过系统开发实践，引导学生掌握模块化设计与工程规范，培养 Web 系统的设计、开发、测试与维护能力。
多媒体技术基础（本科）
本课程介绍文本、图像、音频、视频等多媒体信息的表示、采集、编码与处理方法，涵盖数字化原理、数据压缩、媒体存储与传输等基础知识。结合多媒体素材处理与应用设计实践，培养学生分析媒体数据、选择处理方法及综合运用多媒体技术的能力。
