# 周弈志 · FedOceanLab 学术主页

大连海洋大学个人学术主页，涵盖研究方向、论文与专利、科研项目、教学课程，以及 FedOceanLab 的开源与研究生招生信息。

网站：https://timohaha.github.io

## 本地预览

无需安装前端依赖或构建。直接打开 `index.html`，或在仓库目录运行 `python -m http.server 8000`，访问 http://localhost:8000。

## 文件与维护

- `index.html`：页面内容和联邦学习 SVG 概念图。更新论文请编辑对应的 `data-category` 分组。
- `style.css`：深海蓝主题、响应式布局、键盘焦点和减少动态效果支持。
- `script.js`：移动端菜单、成果分类筛选、导航状态和页脚年份。
- `favicon.svg`：网站图标。

所有资源均来自本仓库，无外部字体、统计脚本或前端框架依赖。关闭 JavaScript 后，导航与全部成果仍可阅读。

原网站的教学成果含模板占位内容，按负责人要求暂时隐藏，课程信息保留。历史内容可在 Git 提交记录中查看。
